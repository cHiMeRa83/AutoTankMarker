## AutoTankMarker
[Download](https://github.com/cHiMeRa83/AutoTankMarker/archive/refs/tags/1.5.zip)

WoW 3.3.5a Addon für Heiler:
- Automatische Tank-Markierung & Fokus-Setzung
- Aggro-Alarm mit deutschem/englischem Chat-Ruf
- Low-Mana & Trink-Whisper an den Tank
- Tank-HP & Tank-Tod Warnungen
- In-Game Einstellungsmenü (/atm config)
